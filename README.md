# Big Mart Sales Prediction

## About the Project

This project predicts the sales of products in Big Mart stores using Machine Learning.

## Objective

The main goal is to build a Machine Learning model that can predict product sales based on the available store and product information.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Steps Performed

1. Loaded the Big Mart sales dataset.
2. Cleaned the data and handled missing values.
3. Analyzed the data to understand important patterns.
4. Prepared the data for Machine Learning.
5. Split the dataset into training and testing data.
6. Created a Gradient Boosting Regressor model.
7. Trained the model using the training data.
8. Predicted sales using the trained model.
9. Evaluated the model performance.

## Result

The model was able to predict sales based on the given product and store information.

## Conclusion

This project helped me understand the basic Machine Learning workflow, including data cleaning, data analysis, model training, testing, and prediction.
